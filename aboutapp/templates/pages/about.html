About this project

This site was developed as part of my full‑stack software development training, with a focus on building a robust, scalable, and maintainable Django application. The project demonstrates core backend engineering principles, including model‑driven design, secure authentication, structured content management, and clean separation of concerns across the application architecture.

The blog system is powered by Django’s ORM and follows a modular app structure, enabling clear organisation of features and future extensibility. Content is stored in a relational database and exposed through dynamic templates that adapt to user‑generated data. The admin interface has been customised to support rich‑text editing through Django Summernote, allowing site administrators to manage posts, comments, and informational pages without modifying source code.

From a technical perspective, the project showcases the integration of third‑party libraries, environment‑specific configuration, and deployment to a cloud‑based hosting platform. The application is container‑ready, adheres to Django’s security best practices, and is structured to support continuous development and feature expansion.

Beyond the technical implementation, this project reflects my commitment to writing clean, readable code and building user‑focused digital experiences. It serves as both a learning platform and a foundation for more advanced development work, including API integration, enhanced content workflows, and improved front‑end interactivity.

If you would like to explore the codebase, contribute ideas, or discuss the project in more detail, feel free to reach out. This site will continue to evolve as I progress through my development journey and expand my technical capabilities.
